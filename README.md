# MyRISCV

Implementazione di una CPU risc-v in verilog, seguendo quanto studiato nel libro: "Digital Design and Computer Architecture, RISC-V Edition (Sarah Harris, David Harris)""

La cpu implementa un subset minimale delle istruzioni RV32I sufficienti a eseguire una gran quantità di programmi. Le istruzioni implementate sono: add, sub, and, or, slt, lw, sw, beq, addi, jal
